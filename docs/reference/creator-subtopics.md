## 경계와 미분류

- FITNESS는 직접 운동·훈련, SPORTS는 종목 경기·분석을 중심으로 구분한다.
- PET는 직접 기르는 동물, 야생 생태는 KNOWLEDGE_SCIENCE, 동물 소재 재편집·유머는 HUMOR_MEMES를 적용한다.
- 코딩 교육은 TECH_PROGRAMMING이다. 교육 형식이라고 KNOWLEDGE로 옮기지 않는다.
- 현재 사건 중심은 NEWS, 원리 설명 중심은 KNOWLEDGE다.
- 여행 목적지 중심은 TRAVEL, 개인 생활 중심은 LIFE다. 브이로그는 별도 형식이다.
- FAN 콘텐츠와 연예 사건 뉴스는 ENTERTAIN_FANDOM / NEWS_CELEBRITY_NEWS로 구분한다.
- HOBBY 공예는 취미 제작, LIFETIP 생활 관리는 실용 수리·살림이다.
- 큰 분야가 여러 개면 복수 주제를 허용한다. 모든 분야에 억지로 세부 태그를 붙이지 않는다.
- OTHER_SPORTS는 명확한 다른 경기 종목만 포함한다. 근거 부족을 기타에 넣지 않는다.
- 개별 게임명·악기명·지역명은 확장 엔티티로 보류한다. 이번 고정 목록에 임의 문자열을 추가하지 않는다.
- 상위 분야 태그는 기존 M3/M4 결과를 유지한다. 세부 분류 때문에 상위 결과를 바꾸지 않는다.
- 세부 주제 미분류일 때 기존 상위 분야 보정으로 폴백한다. 불일치만으로 후보를 제거하지 않는다.

## 실험 원칙

- 비교: M2, 기존 M3/M4, 계층 M3/M4. 입력 468개와 즐겨찾기 집계를 그대로 고정한다.
- 주제 정의를 이름과 함께 임베딩해 M3에 사용하고, 동일 정의·포함·제외 기준을 M4에 제공한다.
- LLM 세부 태그에는 소개글의 정확한 인용 근거를 요구한다. 근거 부족은 빈 태그로 처리한다.
- 세부 주제 정답은 아직 없다. M3 임계값·가산점은 최적값이 아닌 사전에 고정한 탐색 조건으로 구분한다.
- 상위 태그가 없는 경우 세부 분류도 하지 않는다. 잘못된 상위 분류의 영향은 한계로 보고한다.
- 세부 일치는 더 강하게, 상위 일치만 있으면 더 약하게 보정하되 미분류일 때 기존 보정 유지.
- 형식 가중치는 이번에 넣지 않아 세부 주제의 효과를 분리한다.
- 서비스 직접 선택 태그 기준선과 사람 검수는 여전히 별도 작업이다.
