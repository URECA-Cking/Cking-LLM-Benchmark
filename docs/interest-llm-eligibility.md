# 관심 분야 추천 후보 자격 변경

관심 분야 추천은 기존 OpenAI `gpt-5.4-nano-2026-03-17`과 v0.2 분류 프롬프트로
확정한 태그에 관심 분야 코드가 포함되는 크리에이터만 반환한다.
기존 DeepInfra BGE-M3는 소개글과 분야 설명의 코사인 점수로 후보 순위를 계산한다.
FE 디자인과 BE 요청/응답 형식은 그대로 유지한다.

- 빈 소개글, 미분류, 다른 태그는 제외한다. 후보가 부족하면 0~N개를 반환한다.
- 태깅 실패·알 수 없는 코드·중복·3개 초과 응답은 실패로 처리한다. 임베딩 태그로 대체하지 않는다.
- 유사 추천과 같은 모델/프롬프트/소개글 해시 캐시를 공유한다. 17개 분야마다 재태깅하지 않는다.
- `LLM_CONFIRMED_V1`, 태깅 모델, 프롬프트 버전·본문 해시를 배치 식별에 포함하므로
  기존 zero-shot payload/체크포인트와 구분된다. 변경 후 전체 관심 분야 배치를 재생성·적재해야 한다.
- 기존 `INTEREST_M2_V1`/`INTEREST_M3_V1` 전송 식별자는 BE 호환을 위해 유지한다.
  두 식별자 모두 후보 제한 후 코사인 점수만 사용하며 태그 가산점은 없다.
- 이전 `--zero-shot-tau`, `--zero-shot-max-tags`, `--m3-bonus` 인자는 실행 호환용으로만
  유지한다. 새 정책의 후보나 점수에는 영향을 주지 않는다.
- 단독 `interest_cli`도 태그 캐시 미스 시 `OPENAI_API_KEY`가 필요하다.
  `--tag-model`/`--tag-prompt-version`을 지원하며 일일 배치와 같은 기본값을 쓴다.
- 과거 zero-shot M2/M3 평가 결과는 새 정책의 품질 근거로 재사용할 수 없다.
  LLM 오분류 가능성은 남으므로 실제 데이터와 별도 평가셋으로 품질을 검증해야 한다.

## 유사 추천 리뷰 보완

15자 이상 일반 소개에서 LLM 태그가 없으면 임베딩으로 재분류하지 않고 빈 세대를 반환한다.
짧은 소개 M2만 기존 임베딩 tau 분류를 유지한다. taxonomy는 생성기에서 한 번 읽고 allowed_tags 범위로 제한한다.
관심 분야 method M2/M3는 호환 식별자일 뿐 현재 순위가 같으므로 두 방식의 우열 평가로 해석하지 않는다.
호환 옵션 zero_shot_max_tags도 실제 태그 계약에 맞춰 1~3개만 허용한다.
배치 캐시 검증은 지문·근거·상한을 검증하며 모든 자격 후보의 누락 여부를 모델 재호출로 재검사하지 않는다.
