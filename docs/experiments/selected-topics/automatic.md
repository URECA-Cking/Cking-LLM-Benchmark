# 세부 태그 선택 자동 평가

## 목적과 범위

직접 선택 관심사에서 상위 분야만 사용한 추천과 세부 태그를 반영한 추천을 독립 LLM 판정으로 비교한다.
기존 단일 크리에이터100개 사람 평가 및 실제 선택7개 사람 진단과 구분한다.
이번 입력은 taxonomy를 열거·샘플링한 합성 조합이며 실제 사용자 선택 분포가 아니다.

## 사전 고정 조건

| 입력 조건 | 수 | 생성 규칙 |
| --- | ---: | --- |
| 세부 태그1개 | 85 | 정의된 모든 주제 |
| 같은 분야2개 | 51 | 상위17개 분야별 가능한 쌍 중3개 |
| 다른 분야2개 | 34 | 다른 상위 분야 조합에서 고정 seed 추출 |
| 합계 | 170 | seed20261001 |

각 조건의 상위5명 합집합에서 중복을 제거한1,262쌍을 새로 채점한다.
이전 사람 평가53쌍이 포함돼 일치·불일치를 확인할 수 있다.
새 채점 프롬프트·출력 규칙이므로 과거 LLM 판정을 재사용하지 않는다.
기존 사람 답변과 후보 분류 태그·추천 방법·점수·순위는 평가 모델에 전송하지 않는다.
선택 태그의 이름·정의와 후보 소개글만 제공한다.

| 공통 조건 | 값 |
| --- | --- |
| 후보 풀 | 기존4,743명·고정 소개글·캐시 |
| 검색 | 선택 태그의 고유 상위 분야 벡터 평균 |
| 상위 분야 조건 | 후보 상위 태그 일치 시0.2 |
| 세부 조건 | 상위 일치0.1, 해당 분야의 선택 세부 주제도 일치하면0.1 추가 |
| 여러 분야 집계 | 분야별 가산점 최댓값, 최대0.2 |
| 동점·추천 수 | ID 정렬·상위5명 |
| 판정 모델 | gpt-5.4-mini-2026-03-17 |
| LLM 점수 | 관심사마다1 적절 / 0 부적절 / −1 정보 부족 |
| 운영 | 동시4개, 건별 체크포인트·토큰 기록 |

세부 조건은 가산점 증가가 아닌 배분 규칙 전체의 비교다.
다중 관심사 검색·집계 규칙은 단일 크리에이터의 M4/H4와 동일하지 않다.
관련 캐시와 내용·후보·프롬프트·모델·판정 schema를 계약 hash로 고정한다.
후보 세부 태그는 기존 LLM 분류이며 크리에이터 직접 태그 효과는 미검증이다.

## 지표와 해석

주 지표는 선택 관심사 하나 이상에 적합한 P@5다.
판단 어려움은 적절성 미확인으로 계산한다.
보조 지표는 모든 관심사에 적합한 후보 비율, 관심사별 P@5,
목록에서 적절한 후보가1명 이상 있는 관심사 비율(coverage), U 비율이다.
다른 분야를 각각 다루는 후보가 목록에 있으면 관심사 coverage가 높지만,
한 후보가 두 분야를 모두 다루는 비율은 낮을 수 있으므로 둘을 구분한다.

분야·후보를 공유하는 합성 입력의 기술 집계다. 모집단 우월성 구간이나 자동 채택 게이트를 적용하지 않는다.
같은 분야에 여러 주제가 있으므로85개 평균은 실제 사용자 분포를 대표하지 않는다.
분류 태그 일치율은 정답으로 사용하지 않는다.
평가 LLM도 오류가 있으므로53쌍 사람 평가와 일치 수·혼동표·불일치 사례를 별도로 기록한다.
일치율이 높아도 다른 관심사·사용자·서비스 효과가 검증된 것은 아니다.

태그 후보가 적은 주제는85개 단일 입력에 포함된다.
소개15자 미만 후보155쌍도 그대로 평가해 U와 적합성에 반영한다.
짧은 소개는 의미적 정보 부족과 다르다. 후보 고갈·정보 부족을 해결하는 대체 추천 정책의 효과를 시험한 것은 아니다.

## 실행

    python -m src.selected_subtopic_auto prepare \
      --data-dir /path/to/v4 --output-dir results/selected_subtopics_auto_v1

승인된 외부 전송·유료 채점:

    python -m src.selected_subtopic_auto judge \
      --output-dir results/selected_subtopics_auto_v1

전체 완료 후 집계:

    python -m src.selected_subtopic_auto_score \
      --experiment-dir results/selected_subtopics_auto_v1

원문·개별 판정은 로컬 results, 공개 결과는 집계만 보관한다.
성공 응답의 input/output 토큰을 기록한다. SDK 재시도·실패 응답이 추가 비용을 만들 수 있으며 실제 청구액은 미확인이다.
새 프롬프트로53쌍을 다시 채점하지만 사람 답변은 그대로 유지한다.
사람 평가와 LLM 평가 수치를 합산하지 않는다.

| --- | ---: | ---: | ---: | ---: |
| 단일 세부 태그 | 85 | 0.219 | 0.471 | +0.252 |
| 같은 분야2개 | 51 | 0.439 | 0.639 | +0.200 |
| 다른 분야2개 | 34 | 0.347 | 0.718 | +0.371 |

단일 입력85개 중50개에서 개선·32개 동점·3개 하락했다.
주제를 좁혀 순위를 보정하는 규칙의 유망함을 보이는 자동 탐색 결과다. 사람 품질·서비스 전환의 확정 증거로 해석하지 않는다.
단일 입력의 세부 조건도 평균0.471로, 소개·분류·검색 문제를 모두 해결한 결과는 아니다.

### 다중 관심사에서 한쪽으로 쏠리는 문제
| 지표 | 같은 분야2개 | 다른 분야2개 |

| 한 후보가 두 관심사 모두에 적절한 비율, 상위→세부 | 0.102→0.133 | 0.000→0.006 |

다른 분야2개에서 하나 이상 관련된 P@5는 높지만 두 관심사를 모두 충족하는 목록은9/34다.
최댓값 보정·통합 순위만으로는 관심사별 균형을 보장하지 않는다.
분야·관심사별 후보를 나눠 확보하는 슬롯 정책 등은 별도 개발 비교 대상이며 이번 결과에 사후 적용하지 않았다.

### 사람 평가와 불일치

기존53쌍에서 LLM과 사람 일치23/53(43.4%), 불일치30/53이다.
불일치 30건 중 27건은 사람 적절·LLM 부적절로 한 방향에 집중됐다. 방향성은 관찰 사실이지만 사람의 정답성이나 구조적 편향 자체가 입증된 것은 아니다.
세부 적합성을 엄격히 요구하는 평가 기준이 세부 보정 후보에 상대적으로 유리할 가능성은 미검증 가설이다. 조건별 오류 방향을 따로 대조하지 않았으므로 효과의 편향 크기를 확정하지 않는다.
일치율은 평가 신뢰성을 확정하는 게이트로 사용하지 않았다. 오히려 자동 평가를 단독 채택 근거로 쓰기 어렵다는 경고다.

| 사람 | LLM | 쌍 수 |
| --- | --- | ---: |
| 적절 | 적절 | 11 |
| 적절 | 부적절 | 27 |
| 적절 | 정보 부족 | 2 |
| 부적절 | 적절 | 1 |
| 부적절 | 부적절 | 12 |

불일치 근거에는 뷰티 전반 소개가 헤어에 특화됐다고 보기 어렵다거나,
패션 일반 소개로 신발·가방 활동을 확인할 수 없다는 판정이 있었다.
실제 일부 주제를 다루더라도 해당 분야가 핵심이 아니라는 이유로 부적절 처리한 사례도 있어,
채점 기준의 해석 차이 또는 모델 오류 가능성을 함께 점검해야 한다.
사람이 잘못 평가했거나 LLM이 정답이라고 단정하지 않는다.
사람은 적절하다고 본27쌍을 LLM이 부적절로 판단했으므로 두 수치를 섞지 않는다.
선택7개 사람 평가의0.714→0.800과 자동 전체85개 결과는 입력 범위와 평가자가 다르다.

### 결론과 다음 확인

**세부 관심사 보정은 자동 탐색에서도 유망하지만 이 평가기로 사람 채점을 완전히 대체하기에는 근거가 부족하다.**
M4 기본 + 직접 선택 세부 태그의 선택사항 도입은 사람 진단과 함께 검토할 수 있다.
다만 자동 결과만으로 서비스 채택·최적 가중치·전체 사용자 정확도 향상을 확정하지 않는다.
우선 불일치 사례를 개발 자료로 삼아 판단 기준을 명확히 하고, 다음 평가기 버전은 별도 미평가 사람 표본에서 확인해야 한다.
기준을 수정하면 이번170개 입력은 개발 데이터로 취급하고 평가 버전을 새로 만든다.
다중 관심사에는 관심사별 균형 정책의 추가 비교가 필요하다.
