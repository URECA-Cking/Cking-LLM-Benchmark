# 추천 흐름별 M2·M3·M4 비교

## 목적과 기존 실험과의 구분
태그 선택·크리에이터 선택·즐겨찾기 묶음에서 같은 입력과 후보 풀로 M2·M3·M4를 비교한다.
앞선 평균 벡터·순위 합산·필터 실험은 탐색 결과로 유지한다. 이 실험에서는 집계 규칙을 통일한다.
기존 결과와 표본을 이미 관찰했으므로 새 확증 실험이 아니라 고정된 비교 계약의 후속 탐색 분석이다.

## 방법
| 입력 | M2 | M3 | M4 |
| --- | --- | --- | --- |
| 관심 태그 | 선택 분야 설명 평균 벡터와 후보 소개 코사인 | 같은 코사인+선택 태그와 후보 zero-shot 태그 공유 시 보정 | 같은 코사인+선택 태그와 후보 LLM 태그 공유 시 보정 |
| 크리에이터 한 명 | 소개글 코사인 | 코사인+양쪽 zero-shot 태그 공유 시 보정 | 코사인+양쪽 LLM 태그 공유 시 보정 |
| 즐겨찾기 여러 명 | seed별 코사인 중 최댓값 | seed별 M3 점수 중 최댓값 | seed별 M4 점수 중 최댓값 |

즐겨찾기에서는 유사도와 태그 보정을 같은 seed에 대해 계산한 뒤 최대를 취한다.
다른 seed의 높은 유사도와 다른 seed의 태그 일치를 합쳐 보정하지 않는다.
선택·즐겨찾기 대상 전부를 후보에서 제외하고 동점은 채널 ID로 결정한다.
직접 선택한 크리에이터 태그는 M3/M4와 다른 입력이다. 실제 데이터가 없어서 해당 기준선은 미구현이다.

## 고정 조건과 파라미터
- 원본 v4와 기존 flow_v4 계획의 ID·분할·임베딩·태그·분야 설명을 고정한다.
- 기존 v4 dev 채널과 dev 후보만 사용해 tau·M3 bonus·M4 bonus를 다시 선택한다.
- 선택값: tau 0.4296248555, M3 bonus 0.1, M4 bonus 0.2.
- 이 값은 단일 크리에이터 dev에서 선택한 전이 설정이다. 태그·즐겨찾기 경로별 최적값으로 튜닝한 것이 아니다.
- 태그 1개 17, 두 태그 136개 중 고정 표본 17, 크리에이터 400, 즐겨찾기 34: 평가 입력 468개.
- 후보는 전체 입력 587개에 대해 생성하지만 LLM 평가는 위 468개에 한정한다.
- 전체 방법의 평가 후보 합집합은 2,801쌍. 기존 판정 2,763쌍을 재사용하고 신규 38쌍을 분리한다.

## 평가 계약
- 후보 소개와 입력 근거는 방식마다 동일하다. 점수를 보기 전에 입력·후보 내용·텍스트 해시·판정 프롬프트·모델을 기록한다.
- 단일 크리에이터는 기존 공식 판정 질문을 유지한다. 태그·즐겨찾기는 앞선 보조 평가 질문을 유지한다.
- 같은 텍스트·모델·프롬프트·설정의 판정만 재사용한다. 사람 시트는 별도로 비워 둔다.
- P@5와 같은 입력별 M4−M3, M3−M2, M4−M2의 부트스트랩 구간을 보고한다.
- 탐색 참고 규칙은 M4−M3 >= +0.05, 구간 하한 > 0이다. 사람 일치율 0.80은 이번에 확인하지 않았으므로 확정 채택하지 않는다.
- 기존 300개 일반 채널을 기준으로 한 공식 판정은 그대로 유지한다. 새 흐름의 경로별 참고 결과로 구분한다.

## 실행
```bash
cd ~/Desktop/Cking-LLM-Benchmark
.venv/bin/python -m src.flow_m234 \
  --data-dir ~/Desktop/youtube-collect/gold_variants/v4 \
  --source-dir results/real_v4 --flow-dir results/flow_v4 \
  --pilot-dir results/flow_pilot_v4 --output-dir results/flow_m234_v4
# 신규 쌍의 OpenAI 전송·유료 평가를 승인한 경우 --judge 추가
```
기존 산출물을 덮어쓰지 않고 별도 폴더를 사용한다. 같은 계약으로 재실행하면 저장 판정을 재사용한다.
계획·후보·텍스트·판정 계약이 다르면 중단한다. 일부 판정만 완료된 결과는 부분 결과라고 명시한다.
평가 쌍 전체가 채점된 뒤에만 전체 경로 결과로 해석한다.

## 한계
직접 선택 태그가 아닌 모델 태그이며, 즐겨찾기는 합성 표본이다. 실제 사용자 반응과 사람 일치율은 미검증이다.
태그 쿼리는 분야 설명 평균 임베딩이며 실제 사용자 문장 인코딩이 아니다.
같은 분야·크리에이터를 공유하는 입력의 구간은 독립 사용자 표본의 구간이 아니다.
판정과 태깅은 같은 제공자 계열이다. 서비스 태그·인기 지표·직접 선택 태그 기준선은 후속 작업이다.

## 실행 결과 (2026-10-01)

### 해석

- 모든 그룹에서 M4 평균 점수가 가장 높다. 태그 1개는 차이가 작고, 태그 2개는 M4−M3 구간이 0을 포함하고 +0.05에 못 미친다.
- 일반 크리에이터와 두 즐겨찾기 그룹은 수치 기준을 충족한다. 짧은 소개글은 +0.046으로 기준에 못 미친다.
- M3−M2는 태그 1개 0.000, 태그 2개 및 즐겨찾기 각각 +0.012, 일반 소개 +0.005, 짧은 소개 −0.004다.
- 서비스 구현 선택을 확정하지 않는다. 크리에이터가 직접 선택한 태그가 있으므로 그 기준선과 자동 태그 보정의 추가 이득을 별도로 검증해야 한다.
- 앞선 즐겨찾기 M4 수치와 다른 분야 결과가 다르다. 이번에는 같은 seed에 대한 코사인+보정 후 최대를 취해 집계 정의를 통일했기 때문이다.
- 이번 신규 38쌍 토큰: 입력 12,291, 출력 468. 신규 판정 실행 약 10초. 실제 청구액 미확인.
- 전체 테스트 260개 통과(기존 실제 실행 6.01초). 최종 집계는 신규 API 호출 없이 재현 검증한다.
