# 추천 흐름 실험 결과 요약

## 이번 실험의 판단

> **H4를 다음 실제 입력·사람 평가의 우선 후보로 선택한다. 서비스 채택은 아직 확정하지 않는다.**

| 경로 | 관찰한 결과 | 판단 |
| --- | --- | --- |
| 일반 소개글 | H4 0.641 → 0.664, 개선 구간이 0보다 큼 | H4가 유망 |
| 짧은 소개글 | H3 0.556 → 0.578, 개선 구간이 0보다 큼 | H3도 후속 검증 가치 있음 |
| 즐겨찾기 | H4 주 조건 평균 상승, 총량 유지에서는 개선되지 않음 | 가산점 영향을 분리해 검증 |

**점수는 LLM의 추천 적합성 판정이다.** 실제 사용자 반응이나 사람 평가 점수가 아니다.

## 무엇을 비교했나

예를 들어 러닝 크리에이터를 좋아하는 사용자에게 다른 러닝 크리에이터를 추천하는 상황이다. 소개글의 유사도에 분야·세부 주제를 더했을 때 적합성이 높아지는지 비교했다.

| 방법 | 계산 방식 | 자동 태깅 LLM |
| --- | --- | --- |
| M2 | 소개글 의미 유사도 | 없음 |
| M3 | 유사도 + 임베딩으로 추정한 상위 분야 일치 보정 | 없음 |
| M4 | 유사도 + LLM이 분류한 상위 분야 일치 보정 | 사용 |
| H3 | M3에 운동 → 러닝 같은 세부 주제 보정 추가 | 없음 |
| H4 | M4에 LLM이 분류한 세부 주제 보정 추가 | 사용 |

H3 주 조건은 세부 임계값 0.45, 세부 가중치 1.0이다. H4 주 조건의 세부 가중치도 1.0이다.
세부 일치 시 상위 보정 0.5 + 세부 보정 1.0이므로 기존 가산점의 최대 1.5배다.
총량 유지 조건은 세부 가중치 0.5다. 세부 미분류는 기존 상위 태그 보정으로 돌아간다.
즐겨찾기는 각 seed와의 유사도·보정을 먼저 계산하고 그중 최댓값을 쓴다. 모든 seed는 후보에서 제외한다.

## 어떻게 평가했나

- 후보 풀 4,743개, 같은 평가 입력 468개: 태그 34·크리에이터 400·합성 즐겨찾기 34.
- 상위 분야 17개·세부 주제 85개. 콘텐츠 형식 10개는 정의만 하고 점수에는 사용하지 않았다.
- 상위 태그가 있는 4,205개만 세부 LLM 분류. 538개는 호출하지 않았다.
- 각 방법의 상위 5명을 합친 3,709쌍을 평가했다. 기존 판정 2,801쌍 재사용, 신규 908쌍 판정.
- 평가용 LLM이 추천 적합성 0/1을 판정했다. 사람 점수가 아니다.
- P@5는 적합 판정 수/5다. 0.664는 추천 5명 중 평균 3.32명이 적합하다고 판정됐다는 뜻이다.
- 같은 경로 안에서 비교한다. 경로별 판정 질문이 달라 서로 다른 경로의 절대 점수를 직접 비교하지 않는다.

## 핵심 결과

P@5는 상위 5명 중 적합 판정을 받은 비율이다. **표의 H3·H4는 주 조건**이며, 경로별로 같은 입력에서 비교했다.

| 추천 입력 | 표본 수 | M2 | M3 | M4 | H3 | H4 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 일반 소개글 | 300 | 0.583 | 0.588 | 0.641 | 0.589 | **0.664** |
| 짧은 소개글 | 100 | 0.560 | 0.556 | 0.602 | 0.578 | **0.618** |
| 같은 분야 즐겨찾기 | 17 | 0.541 | 0.553 | 0.624 | 0.588 | **0.706** |
| 여러 분야 즐겨찾기 | 17 | 0.612 | 0.624 | 0.694 | 0.659 | **0.729** |

### 세부 태그와 가산점의 영향

주 조건은 세부 태그가 일치할 때 기존보다 가산점을 더 준다. 아래 총량 유지 조건을 함께 봐야 한다.

| 추천 입력 | 기존 M4 | H4 총량 유지 | H4 가산점 증가 |
| --- | ---: | ---: | ---: |
| 일반 소개글 | 0.641 | 0.655 | 0.664 |
| 짧은 소개글 | 0.602 | 0.610 | 0.618 |
| 같은 분야 즐겨찾기 | 0.624 | 0.612 | 0.706 |
| 여러 분야 즐겨찾기 | 0.694 | 0.694 | 0.729 |

**즐겨찾기의 상승을 세부 태그만의 효과로 설명할 수 없다.** 총량 유지 조건에서는 기존 M4보다 좋아지지 않았다.

상위 태그만 선택한 입력 34개는 세부 태그를 추정해 넣지 않았으므로 기존 M3/M4와 H3/H4의 추천이 같다.
사용자가 세부 관심 태그를 직접 선택하는 화면의 효과는 검증하지 않았다.

## 개선을 어디까지 말할 수 있나

아래는 같은 입력에 대한 차이의 탐색 95% 부트스트랩 구간이다. **구간에 0이 포함되면 개선을 확인하지 못한 것으로 읽는다.**

| 입력 | H3−M3 | 95% 구간 | H4−M4 | 95% 구간 |
| --- | ---:| --- | ---:| --- |
| 일반 소개글 | +0.001 | [-0.013, +0.016] | +0.023 | [+0.011, +0.035] |
| 짧은 소개글 | +0.022 | [+0.008, +0.040] | +0.016 | [0.000, +0.032] |
| 같은 분야 즐겨찾기 | +0.035 | [-0.035, +0.118] | +0.082 | [-0.012, +0.200] |
| 여러 분야 즐겨찾기 | +0.035 | [0.000, +0.071] | +0.035 | [-0.035, +0.129] |

- H4 일반 소개: 개선 구간이 0보다 크다. 다만 세부 정보와 가산점 변경을 함께 적용한 조건이다.
- H3 일반 소개: 차이가 거의 없고 구간에 0이 포함된다. 짧은 소개에서는 구간이 0보다 크다.
- 즐겨찾기: H4 평균 상승은 관찰했지만 두 그룹 모두 구간에 0이 포함된다. 각 17개 합성 입력이다.
- H4 총량 유지의 일반 소개 점수도 0.655로 상승했으나, 이를 별도 확증 결과나 최적 조건으로 주장하지 않는다.

## 아직 검증하지 않은 것

같은 v4 test를 관찰하며 발전시킨 탐색 실험이다. 고정 입력 비교는 가능하지만 새로운 데이터에 대한 확증은 아니다.
직접 선택한 크리에이터 태그·실제 즐겨찾기·인기순·사람 평가·사용자 반응은 미검증이다.
인용 기록은 원문 출처 확인이다. 그 구절이 세부 주제를 의미적으로 뒷받침하는지는 검증하지 않았다.
태깅과 판정은 같은 제공자 계열이며, 세부 주제 정답 라벨로 분류 정확도를 검증하지 않았다.
원문·판정·벡터는 Git 제외이므로 외부 v4 데이터와 로컬 캐시 없이 실험 수치를 독립 재현할 수 없다.
