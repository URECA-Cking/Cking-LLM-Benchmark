# v5 개발 표본 실험 — 2026-10-14

v5는 이번 고정 개발 표본에서 v4보다 형식 통과와 세부 의미 지표가 악화됐다. 개선 가설은 확인되지 않았다.
기본값은 v2를 유지하고 v5와 중복 억제 대조 조건은 명시적 실험 옵션으로 남긴다.
사용자 요청에 따라 기존 v2/v4 결과를 재사용했고 **v5만 새 API 호출**했다. 결과를 본 뒤 프롬프트를 고쳐 재호출하지 않았다.

## 기존 v4 원인 진단

검증기가 처음 보고한 오류 기준으로 중복은 **8회/3채널**, 정확한 인용 오류는 **3회/3채널**이다.
최종 실패 2채널은 각각 세 시도 모두 중복 오류다. 같은 상위를 서로 다른 소재나 세부 주제별로
반복 출력했고 일부 응답은 같은 세부 코드도 여러 인용 객체로 출력했다.
인용 오류 3회는 비연속 구절을 자연스럽게 재조합한 인용, 원문 외 번역 표현, 빈 evidence였다.
첫 오류 뒤에 가려진 오류도 있어 원본 진단에는 모든 중복/인용 결함을 별도로 기록했다.
이 결함 객체 수를 오류 호출 수나 채널 수와 합산하지 않는다.

공통 성공 41개에서 누락 7태그는 6채널이다. LIFE_PERSONAL 3, LIFE_STORIES 1,
FASHION_CLOTHING 1, HOBBY_CRAFTS 1, ENTERTAIN_FILM 1을 원본 AI 기준과 정의에 대조했다.
AI 재검토는 **명확한 근거 4태그, 근거 불충분 1태그, 분류 경계 보류 2태그**로 기록했다.
단독 일상 키워드는 본인의 기록을 보장하지 않고, 의류 제작의 패션 분류와 짧은 작품 형식의 영화 분류는
팀 합의가 필요하다. 원본 AI keep 판정은 수정하지 않았으므로 아래 수치는 원본 기준 그대로다.
사람 합의는 미수행이다. LIFE 일상 기록/개인 사연, 코디/취미 제작, 영화 작품/일반 편집 경계에 대한
합성 예시는 실험 가설이며 확정된 사람 기준이 아니다. 후보 생략은 응답에서 관찰했지만
모델 내부에서 문자 일치나 core 조건 때문에 생략했는지 단정할 수 없다.

## 결론과 미수행 범위

이번 v5는 개발 표본의 AI 기준에서도 개선되지 않았다. 자동 중복 삭제나 인용 보정 없이 오류를 보존했고
v5를 기본값으로 승격하지 않았다. 합성 테스트 통과는 실제 모델 개선의 근거가 아니다.
대조 조건의 실제 실행, 팀 경계 합의, 사전 채택 기준, 실제 사람 기준, 독립 홀드아웃은 미수행이다.
이번 결과로 기준을 사후 설정해 채택하지 않는다. #66의 사람 검증·팀 판단을 대체하거나 이슈 전체 완료로 처리하지 않는다.
향후 독립 검증은 기존 도구의 `register --v4-v5`로 새 사람 기준과 채택 기준을 먼저 고정한 뒤 수행할 수 있다.
이번 승인으로 해당 경로를 실행하지 않았다. taxonomy 확정·BE 시드·추천 순위 개선·서비스 E2E는 별도 작업이다.
