# 현재 추천 방식의 결과와 선택

## 적용 후보

**소개 기반 추천은 일반 소개 M4, 짧은 소개 M2를 잠정 선택한다.**
자동 세부 태그 H4는 M4보다 평균이 조금 높았지만 추가 효과가 작고 불확실했다.
직접 선택 세부 관심사는 별도 제품 선택사항으로 검토하며 자동 평가만으로 채택을 확정하지 않는다.

## 1. 소개 기반 최종 사람 평가

같은 4,743개 후보 풀에서 미평가 입력 100개를 골랐다. 일반 75개·짧음 25개에서
다섯 방식의 추천 합집합 801쌍을 사용자 1명이 방법명을 숨긴 상태로 채점했다.

| 입력 | M2 | M3 | M4 | H3 | H4 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 일반 소개 75개 | 0.736 | 0.755 | 0.827 | 0.749 | 0.835 |
| 짧은 소개 25개 | 0.648 | 0.656 | 0.680 | 0.664 | 0.688 |

P@5는 추천 5명 중 적절한 후보의 평균 비율이다.
일반 소개 M4−M3는 +0.072, 그룹별 다중 비교 보정 99% 구간은 [+0.024, +0.131]이다.
평균은 사전 기준 0.03을 넘고 개선 방향도 확인됐지만 최소 0.03 개선까지 입증하지는 못했다.
결과 해석에서는 평균 개선 ≥0.03이고 99% 구간 하한 >0인 추가 복잡성을 잠정 정당화했다.
이 결합 정의는 사전 계약에 없었으므로 결과 보고 단계의 판단으로 구분한다.

짧은 소개는 n=25에서 차이를 충분히 확인하지 못해 단순한 M2를 잠정 선택한다. 동등성이나 M2 우월성의 증명은 아니다.

## 2. 직접 선택 세부 태그의 사람 진단

1명이 고른 7개 관심사에서 53쌍을 채점했다. 소개 기반 100개 입력 실험과 별개다.

| 비교 | 상위 분야만 | 직접 세부 태그 보정 |
| --- | ---: | ---: |
| 관심사 7개 평균 P@5 | 0.714 | 0.800 |
| 베이킹 | 0.000 | 0.600 |
| 코딩 | 0.200 | 0.200 |

평균 개선은 베이킹 1개 입력에서 발생했고 다른 6개는 적절 후보 수가 같았다.
직접 선택은 의도를 좁히는 데 도움이 될 가능성이 있지만 전체 사용자 개선을 확정한 결과는 아니다.
후보의 세부 태그는 기존 LLM 분류이며 크리에이터가 직접 등록한 태그의 효과는 미검증이다.

## 3. 선택 조합의 자동 평가

단일 태그 85개·같은 분야 2개 선택 51조합·다른 분야 2개 선택 34조합을 고정했다.
1,262쌍을 평가 GPT가 후보 소개와 선택 관심사 정의만 보고 관심사별로 판정했다.

| 입력 조건 | 상위 분야만 | 세부 태그 보정 |
| --- | ---: | ---: |
| 단일 85개 | 0.219 | 0.471 |
| 같은 분야 2개·51조합 | 0.439 | 0.639 |
| 다른 분야 2개·34조합 | 0.347 | 0.718 |

이 표는 LLM이 관심사 하나 이상에 적절하다고 판정한 P@5다.
사람 평가와 일치한 판정은 23/53쌍뿐이며 불일치 30건 중 27건은 사람 적절·LLM 부적절이다.
평가 기준이 세부 보정 후보에 유리할 가능성은 미검증 가설이며 구조적 편향이 입증된 것은 아니다. 판정 기준 해석과 모델 오류를 점검해야 하므로
자동 점수만으로 사람 평가를 대체하거나 서비스 채택을 확정하지 않는다.
다른 분야에서 두 관심사를 모두 반영한 추천 목록도 9/34개에 그쳐 균형 정책이 필요하다.

## 서비스에 옮길 때

- M4를 기본 후보 엔진으로 검토하고 조회 중에는 저장된 벡터·태그를 재사용한다.
- 짧은 소개 분기는 기존 기준인 소개 15자 미만이다. 의미적 정보 부족 판정과 구분한다.
- 세부 선택은 선택사항으로 검토한다. 자동 세부 분류 H4를 기본 채택한다는 뜻이 아니다.
- API 임베딩의 벡터·파라미터·순위 정합성과 소개 부족·후보 부족 처리를 검증한다.
- 실제 즐겨찾기·사용자 태그 데이터와 클릭·즐겨찾기 전환은 추가 검증 대상이다.

이 결과는 같은 후보 풀의 오프라인 비교다. 새 채널 일반화와 서비스 만족도를 입증하지 않았다.
