# 개발 표본 v2/v4 실제 비교 — 2026-10-14

사용자가 원문 외부 전송과 두 버전 합계 최대 300회의 유료 API 호출을 승인한 뒤,
고정한 개발 표본 50개를 새 v2와 v4로 실행했다. 기존 역사적 v2 결과를 소급 보정하지 않았다.
참조 판정은 사용자가 위임한 **AI 대리 검수**이며 독립적인 사람 정답이 아니다.

v4는 형식 통과와 과잉 억제에서 개선됐고 공통 성공 표본의 세부 F1도 0.641→0.815로
높아졌다. 세부 누락은 4→7로 늘어 precision과 recall의 교환 관계가 관찰됐다.
기본값 v2 유지는 **사전 채택 기준과 독립 홀드아웃 검증이 없어 변경을 보류하는 상태**이며,
v4가 전반적으로 더 나쁘다는 결론이 아니다. 독립 홀드아웃과 최종 팀 채택 판단은 미수행이다.
이 비교는 양성 세부 태그 29개의 소규모 AI 기준에 대한 진단이고 검수자도 일부 과거
자동 라벨을 본 비블라인드 판정이다. 누락 3개 차이가 recall 약 10.3%p를 움직인다.

## AI 기준 대비 누락·과잉

성공 출력의 태그만 정답 비교에 포함하며 hold는 제외한다. 모델 실패로 비교할 수 없는
태그 수를 별도로 표시한다. 두 실행의 성공 표본이 다르므로 아래 원시 수치의 차이를
그대로 개선량으로 읽지 않는다.

| 항목 | 새 v2: 성공 42개 | 새 v4: 성공 48개 |
| --- | ---: | ---: |
| 상위 누락 / 과잉 | 5 / 6 | 6 / 4 |
| 세부 누락 / 과잉 | 4 / 25 | 10 / 4 |
| 성공 중 참조 양성 상위 / 세부 | 39 / 33 | 46 / 41 |
| 모델 실패로 비교 못한 상위 / 세부 판정 태그 | 134 / 679 | 34 / 170 |

전체 AI 기준의 hold는 상위 16개와 세부 16개이며 15개 채널에 걸쳐 있다.
보류를 전부 부정이나 모델 정답으로 바꾸어 집계하지 않았다.

## 양쪽 모두 성공한 41개

동일한 41개와 동일한 hold 제외 기준으로 비교했다. 어느 한쪽이라도 실패한 9개는
제외되어 성공 선택 편향이 남는다. 보류 때문에 평가한 상위·세부 코드 수도 구분한다.

| 항목 | 새 v2 | 새 v4 |
| --- | ---: | ---: |
| 상위 누락 / 과잉 | 5 / 5 | 6 / 4 |
| 세부 누락 / 과잉 | 4 / 24 | 7 / 3 |
| 상위 양성 태그 / 비교 태그 분모 | 37 / 683 | 37 / 683 |

v4에서 과잉 세부 태그는 21개 줄었고 누락은 3개 늘었다. F1은 precision과 recall의
조화평균이며 이 표의 사후 설명 지표다. F1 최대화를 사전 채택 기준으로 합의한 것은 아니다.
공통 표본에서 v4의 누락은 LIFE_PERSONAL 3개, LIFE_STORIES·FASHION_CLOTHING·
HOBBY_CRAFTS·ENTERTAIN_FILM 각 1개다. 이 해석은 해당 AI 기준에 대한 진단이며
사람 의미 품질이나 추천 순위 개선의 검증이 아니다.

## 역사적 집단별 형식 통과

각 집단의 전체 채널 수를 분모로 사용했다. 집단 중복 채널은 3개이며 집단을 합산하지 않는다.

| 과거 v2 최종 실패 | 7 | 1/7 / 3/7 | 4/7 / 6/7 |

## 검증과 남은 작업

두 summary를 원본 attempts의 연속 번호·상태·첫 시도/최종 성공·revision과 대조했다.
입력·taxonomy·정책·스키마·프롬프트·모델·호출 조건·AI 기준 해시가 일치하는지 검증했다.
성공 90개 응답의 원본 후보 JSON이 저장 revision의 후보와 같은지도 확인했다.
usage의 입력+출력=총 토큰과 승인 호출 상한을 대조했다.
전 단계 관련 합성 테스트는 265개 통과했으며 이번에는 코드 변경 없이 실제 실행을 검증했다.

현재 기본값은 **v2 유지**다. v4의 precision·F1 향상은 관찰됐으며 v4가 더 나쁘다는
판정으로 v2를 선택한 것이 아니다. 사전 채택 기준과 독립 홀드아웃 검증이 없어 기본값
변경을 보류한다. 이 비교의 양성 세부 태그는 29개로 작아 누락 3개가 recall을 약 10.3%p
움직이고, AI 판정 역시 과거 자동 라벨 일부를 본 비블라인드 기준이라는 한계가 있다.
채택 임계값에 대한 팀의 사전 합의는 이번 AI 진단에 포함되지 않았으며 결과를 본 뒤
임계값을 만들어 채택했다고 표시하지 않는다.
50개는 프롬프트 예시가 유래한 개발 표본이고 AI 검수도 일부 과거 자동 라벨을 본
비블라인드 판정이다. 독립 사람 기준·독립 홀드아웃·최종 팀 판단은 수행하지 않았다.
홀드아웃 결과를 본 뒤 프롬프트를 수정한다면 그 표본은 개발 표본으로 재분류해야 한다.
taxonomy 확정·BE 시드·추천 순위·서비스 E2E·배포는 별도 작업이다. 이슈 전체 완료로 처리하지 않는다.

재현 명령과 AI 모드 격리는 [평가 가이드](../guides/detail-tagging-holdout.md)를 따른다.
